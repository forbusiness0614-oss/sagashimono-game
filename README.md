# さがしものゲーム — おもちゃの部屋（高難度版）

HTML・CSS・JavaScriptのみで動く静的ゲームです。外部API・有料サービス・ビルド・パッケージインストールは不要です。大富豪ゲームとは別プロジェクトです。

## 今回の変更

- 背景内のタイトル・タイマー・ヒント・一覧を廃止。`stage1.png` は部屋だけのオリジナル写真風画像に置き換えました。
- タイトル、タイマー、ヒント、発見状況、探すもの一覧はHTMLで描画します。
- 開始ボタンを押してから `performance.now()` の経過時間を表示します。開始前は00:00、クリアで停止、再スタートでリセットします。タイマーのコールバック回数を時間として数えないため、タブが非表示でも復帰時に経過時間へ追従します。
- 小さな対象、類似色・類似形の雑貨、多数の小物を配置して高難度化しました。5〜10分は設計目標で、実測プレイ時間を保証するものではありません。
- 全10個の輪郭ポリゴンを画像の実位置に合わせて再設定しました。画像と判定とマーカーを同じ親要素で変形し、相対座標で表示します。
- 1〜4倍の拡大縮小、ドラッグ、ホイール、タッチ・ピンチに対応。ヒントは3回、対象へ移動し6秒間強調します。

## ローカルで起動

このフォルダーで実行してください。

```sh
python3 -m http.server 8002 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:8002/` を開きます。

## 動作検証

```sh
node --check game.js
python3 tests/smoke.py
```

サーバーを起動した状態で実行します。ブラウザー検証のみ、Python Playwrightと `/usr/bin/chromium` が必要です。ゲームの実行には不要です。390px・820px・1440px幅で、全10個×通常・2倍・4倍の正解判定、各アイテムのヒント、3回上限、空白への誤タップ、クリア画面、開始前・開始後・クリア後のタイマー、再スタートを確認します。タッチ、ピンチ、ドラッグ、画面幅変更後の判定も確認します。

## 公開済みリポジトリの更新

既存の `forbusiness0614-oss/sagashimono-game` にこのフォルダーのファイルを上書きします。新しいフォルダーを一段挟まず、`index.html`・`style.css`・`game.js`・`stage1.png` がリポジトリ直下になるようにしてください。

iPadの場合：

1. 更新ZIPを「ファイル」に保存してタップし、展開します。
2. Safariで既存の sagashimono-game リポジトリを開きます。
3. `Add file → Upload files` で `index.html`・`style.css`・`game.js`・`stage1.png` をまとめて選択します。
4. `Commit changes` で保存します。提案用ブランチを選ぶ場合は続けてPull Requestを作成してください。
5. `Actions` でPagesのデプロイ完了を確認します。必要なら `Settings → Pages` で `Deploy from a branch / main / (root)` を選びます。
6. 公開ページを再読み込みします。古い画像が表示される場合はSafariでタブを開き直してください。
